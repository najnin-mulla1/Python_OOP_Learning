# ATM System Using Python OOP

## About the Project
I created a simple ATM simulation using Python to practice Object-Oriented Programming (OOP).

## Features
- Check balance
- Create PIN
- Verify PIN
- Deposit money
- Withdraw money

## Concepts Learned
- Classes and Objects
- Constructor (`__init__`)
- `self` keyword
- Methods
- Conditional statements

## How to Run
Run the following command in the terminal:

```bash
python ATM_Application.ipynb
```
